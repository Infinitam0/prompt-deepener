# Glossary: prompt-deepener

**Original prompt**: the prompt exactly as Sytze typed it, before any deepening.
_Avoid_: raw prompt, input

**Improver text**: the fixed instruction that asks for a deeper (not bigger) version of a task: four questions, then a rewrite. Sytze's own wording by default.
_Avoid_: meta-prompt, template

**Deepening**: the four answers the improver text asks for about one original prompt: what a top professional would do that wasn't asked; the rawest material they'd start from; their specific methods and tools; what outside evidence would show the result is right.
_Avoid_: analysis, critique

**Deepened prompt**: the rewrite of an original prompt that asks for exactly what the deepening found. Never sent without Sytze reading it.
_Avoid_: improved prompt, enhanced prompt

**Deepen**: to run an original prompt through the improver text, producing a deepening and a deepened prompt.
_Avoid_: improve, enhance, expand ("bigger" is exactly what it must not do)
